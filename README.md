# №10 Зертханалық жұмыс: Виртуализация технологияларын меңгеру (VMware, KVM, VirtualBox)

**Пәні:** DevOps үшін операциялық жүйелер
**Орындаған:** Мустафа Бағлан Жанболатұлы

---

## 1. Кіріспе
Виртуализация – бұл бір физикалық компьютерде бірнеше операциялық жүйелерді бір уақытта іске қосуға мүмкіндік беретін технология. Аппараттық, желілік және сақтау виртуализациясы болып бөлінеді.

---

## 2. 1-тапсырма: VirtualBox көмегімен виртуалды машина жасау

* **Қолданылған ISO:** Ubuntu / Windows
* **RAM мөлшері:** 2048 МБ
* **Орнату уақыты:** ~15 минут

**Сұрақтар мен жауаптар:**
* *Қанша ОЗУ бөлдіңіз?* — 2048 МБ (2 ГБ) бөлдім.
* *Виртуализация өнімділігіне қалай әсер етеді?* — Физикалық аппараттық ресурстарды тиімді бөлісу арқылы бірнеше ортаны қатар іске қосуға мүмкіндік береді, бірақ тым көп ресурс бөлу негізгі жүйенің жылдамдығына әсер етуі мүмкін.
